LiteTV

Lightweight live TV for Android TV.

A free IPTV player for Android TV. Bring your own M3U playlists and guide (EPG) files; LiteTV plays the channels, shows what's on, and keeps memory use low.

Download the APK View on GitHub

Free and open source (MIT), no ads. LiteTV does not include any channels, playlists or guide data: you add your own.

An IPTV app made for the TV remote

Your M3U playlists

Live channels from one or more M3U playlists, with quick switching, search across all of them, favorites and hidden channels.

Full TV guide (EPG)

Now and next on every channel, a guide screen by day and a program info page. 2 to 14 days, refreshed on a schedule.

Low memory use

The guide is stored on disk, not in RAM, so even long guides run smoothly on cheap Android TV boxes and sticks.

Set up from your phone

Scan a QR code and add playlists and guides on your phone instead of typing with the remote.

Per-channel settings

Audio track, subtitles, aspect ratio and audio delay to fix out-of-sync sound, plus clear stream error messages.

Themes and backup

Six themes plus your own colors, seasonal decorations, and a backup file for playlists, guides and favorites.

Install on Android TV

  1. Download the latest LiteTV APK.
  2. Turn on Developer options on the TV (Settings → Device Preferences → About, tap Build 7 times) and enable network debugging.
  3. Install it with adb: adb connect <tv-ip>:<port> then adb install -r LiteTV-x.y.z.apk
  4. Open LiteTV, press OK, choose Playlists and scan the QR code to add your playlists from your phone.

More details, remote control buttons and building from source are in the README.
